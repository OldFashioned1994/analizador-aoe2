# Analizador AoE2

Instaladores de **Analizador AoE2**: analizador de partidas grabadas, entrenador y guía de
civilizaciones para Age of Empires II: Definitive Edition. Uso personal, entre amigos.

## Instalar

- **Windows**: bajá `AnalizadorAoE2-Setup-<versión>.exe` de la [última versión](../../releases/latest) y abrilo.
- **Mac**: bajá `AnalizadorAoE2-Mac-<versión>.zip`, descomprimilo y seguí el `LEEME.txt` que trae.

Una vez instalada, la app se actualiza sola: baja las versiones nuevas en segundo plano y las
instala al cerrarse. Cada versión está firmada; la app no instala nada cuya firma no coincida.
